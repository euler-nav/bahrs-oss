# Introduction

The program exports debug output of BAHRS to a MAT file so that data can be explored in Matlab or Octave.

# Usage

This is a command line application. Requires 2 arguments:

1. binary data log name
2. name of a MAT file to export to

Example:

- **DebugOutputToMat.exe** *bahrs_debug_data_log.bin* *bahrs_debug_data.mat*
