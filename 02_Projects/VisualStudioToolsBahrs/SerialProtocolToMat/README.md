# Introduction

The program exports serial port output of BAHRS to a MAT file so that data can be explored in Matlab or Octave.

# Usage

This is a command line application. Requires 2 arguments:

1. binary data log file name
2. name of a MAT file to export to

Example:

- **SerialProtocolToMat.exe** *bahrs_data_log.bin* *bahrs_data.mat*
