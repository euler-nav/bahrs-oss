# Introduction

The folder contains source files implementing functions that override/intercept memory allocation/deallocation functions and operators from C/C++ standard library.

# Folder content

- *ams_std_memory_functions.cpp*: implements C and C++ memory API overwrites
- *sysmem.c.txt*: implementation of *_sbrk()* generated by STM32CubeIDE. The function is the backbone of all memory allocators in the C/C++ standard library used by STM32CudeIDE toolchain.
