# BAHRS software release PF_2_0 for hardware rev. 2

This is a pre-built standard EULER-NAV Baro-Inertial AHRS software that the devices are shipped with starting from August 2026.

## Content

1. Firmware (.hex file)
2. Default NVM image: nvm_image_pf_2_0_default.bin
3. NVM map file: nvm_map.json
4. Serial protocol converter: see the folder *..\Tools\*

## Release notes

1. Introduced three EKFs running in parallel.
2. Added fault detection and isolation capability for roll, pitch, altitude, and vertical speed
