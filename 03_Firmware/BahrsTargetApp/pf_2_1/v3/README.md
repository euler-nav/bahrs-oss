# BAHRS software release PF_2_1 for hardware rev. 3

This is a pre-built standard EULER-NAV Baro-Inertial AHRS software that the devices are shipped with starting from December 2026.

## Content

1. Firmware (.hex file)
2. Default NVM image: nvm_image_pf_2_1_default.bin
3. NVM map file: nvm_map.json
4. Serial protocol converter: see the folder *..\Tools\*

## Release notes

1. Introduced three concurrent magnetic heading estimation lanes
2. Added fault detection and isolation capability for magnetic heading output
